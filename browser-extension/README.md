# CareerPilot Job Clipper

Chromium Manifest V3 extension bundled with Week 7.

1. Start CareerPilot backend.
2. Open **Integrations** in CareerPilot and generate a clipper token.
3. Load this folder as an unpacked extension in Chrome/Edge.
4. Open any public job page and click the extension.
5. Confirm the API URL and paste the one-time token.
6. Click **Save to CareerPilot**.

The extension only posts the public page data to `/integrations/clipper/jobs`. The token is revocable from CareerPilot.
